# Healthcare Data Analysis

## Project Overview

This project focuses on analyzing healthcare data to identify patterns in patient information, medical test results, and abnormal conditions.

The project follows a data analytics workflow involving data cleaning, transformation, analysis, and visualization using Python and Streamlit.

## Objective

The main objectives of this project are:

- Clean and prepare healthcare data for analysis
- Analyze patient and medical test information
- Identify abnormal test conditions
- Compare test results across patients
- Generate meaningful healthcare-related insights
- Present the analysis through an interactive Streamlit application

## Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Excel / CSV
- Jupyter Notebook

## Data Processing

The dataset was cleaned and prepared using Python.

The data processing includes:

- Handling missing values
- Removing unnecessary data
- Cleaning column names
- Formatting data types
- Preparing data for analysis
- Creating calculated values for analysis

## Analysis

The project analyzes healthcare information such as:

- Patient information
- Medical test names
- Test results
- Abnormal conditions
- Number of patients
- Test-wise analysis
- Patient-wise analysis

## Streamlit Dashboard

An interactive Streamlit application was developed to present the analysis.

The application allows users to explore healthcare data and view:

- Patient information
- Test information
- Number of patients
- Abnormal condition counts
- Test-wise results
- Healthcare data summaries
